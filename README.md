# 网课视频后台播放助手 (course-video-autoplay)

纯 PowerShell 实现的网课视频后台挂播工具，**零第三方依赖**——Windows 自带 PowerShell 5.1 + 任意 Chromium 浏览器即可运行，脱离任何 AI 工具独立使用。

## 功能特性

| 功能 | 说明 | 平台支持 |
|---|---|---|
| 后台挂播 | 浏览器窗口最小化到任务栏，视频自动播放，不占桌面 | 通用 |
| 倍速维持 | 直接驱动 `video.playbackRate`（2~16x），页面内 0.1 秒级高频维持 | 通用 |
| 倍速显示同步 | 播放器界面上的倍速按钮显示与实际速度保持一致 | 自动检测适配（MOOC 实测有效） |
| 智能保活 | 暂停自动恢复播放、页面刷新自动重注入 | 通用 |
| 浏览器自愈 | 浏览器意外关闭自动重启，并回到上次观看的视频页 | 通用 |
| 多标签定位 | 遍历所有标签页自动找到真正带视频的那个 | 通用 |
| 视频内答题助手 | 弹题自动作答 + 题库积累 + 错题自动学习 | 中国大学MOOC 实测可用 |
| 边播边同步完成度 | 播放时服务端观看记录跟随真实进度，播完自动判定完成 | 雨课堂系平台 |
| 完成度补齐 | 批量补报心跳把观看覆盖率一次补满 | 雨课堂系平台 |

> 设计原则：**核心功能不绑定任何平台**。平台增强均为"检测到才启用"，检测不到自动跳过，不影响播放。

## 环境要求

- Windows 7/10/11（自带 PowerShell 5.1 即可，无需安装任何东西）
- Chrome / Edge / 360 极速浏览器（任一）
- 课程平台的账号

## 快速开始

1. **下载**：Clone 本仓库或直接下载 ZIP，解压到任意固定位置（如 `D:\cvap\`，登录态存在本地配置里，建议别挪动）
2. **双击 `启动.bat`**：弹出菜单窗口和专用浏览器窗口
3. **登录**：在弹出的浏览器里登录课程平台（**只需一次**，之后长期免登录）
4. **刷课**：在这个浏览器里点进课程、打开要刷的视频 → 回到菜单按 `1` → 直接回车
5. 程序自动接管：前台缓冲 → 最小化 → 倍速播放 → 保活 → 自动答题
6. 收工：菜单按 `5` 停止，或直接关掉菜单窗口

## 菜单说明

| 选项 | 功能 | 说明 |
|---|---|---|
| 1 | 播放视频 | 直接回车 = 播放当前浏览器里已打开的视频页；也可粘贴链接 |
| 2 | 查看播放状态 | 显示所有标签页的视频进度 |
| 3 | 设置倍速 | 如 2 / 4 / 8，上限以各平台档位为准 |
| 4 | 恢复窗口到前台 | 登录、手动查看页面时用 |
| 5 | 停止后台播放 | 停止保活并关闭程序浏览器 |
| 6 | 完成度同步 | 补齐观看覆盖率（目前仅适配雨课堂系平台） |
| 7 | 无头模式 | 浏览器隐形（注意：部分平台播放器在隐形启动下不挂载） |
| 0 | 退出 | — |

## 视频内答题助手

视频播放中弹出选择题时（答完才能继续放），程序自动处理：

- **题库里有答案** → 自动选、自动提交、自动点"继续学习"恢复播放
- **题库里没有** → 先不乱答（避免答错计入成绩），把题目记录到 `questions.txt` 并在菜单窗口提示
- **答错了** → 自动把页面显示的正确答案学进题库，同题下次必对

**题库文件**：浏览器配置目录下的 `answers.txt`（默认路径 `C:\Users\<用户名>\AppData\Local\Temp\KaoKePlayer\profile\answers.txt`），每行一条，格式：

```
题干关键词|答案字母
```

示例：

```
中国建造的发展目标|A
智能建造的特征|B
```

> 关键词写题干里独特的一段即可，程序按"题目包含关键词"匹配。

## 工作原理

通过 Chrome/Edge 的 `--remote-debugging-port` 调试协议（CDP）控制浏览器：

- 穿透 iframe 与 Shadow DOM 定位视频元素（逐个执行上下文探测）
- 注入页面内定时器维持倍速与保活，独立于主程序运行
- 播放器实例、课程参数均从页面动态读取，不写死任何平台账号或地址
- 保活循环运行在隐藏的后台作业里，菜单窗口随时可操作

## 常见问题

**Q：菜单窗口可以关吗？**
保活循环运行在隐藏后台作业里，关菜单窗口不影响当前播放；但失去"自动重启浏览器"等保护。建议最小化挂着。

**Q：为什么播放器显示的倍速和实际不一样？**
v1.3 已自动同步显示。若仍遇到，可在播放器倍速菜单手动选一次，程序会维持它。

**Q：浏览器自己关了怎么办？**
v1.3 会自动重启并回到上次观看的视频页；旧版本请重新双击 bat 按 1。

**Q：提示"等待登录"一直不动？**
先确认弹出的浏览器里已登录；再确认打开的是**视频播放页**（课程介绍页上没有播放器）。多开了几个标签也没关系，程序会自动找到带视频的那个。

**Q：完成度同步对慕课有用吗？**
暂未适配。慕课的观看进度靠平台自身记录，挂播即可；雨课堂系平台的完成度功能完整可用。

**Q：杀毒软件/安全软件报警怎么办？**
本工具通过浏览器调试协议（CDP）控制浏览器，部分安全软件会对此提示。源码全部开放可自行审阅，选择信任即可。
